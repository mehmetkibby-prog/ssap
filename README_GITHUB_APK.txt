SİVİL SAVUNMA — SAMSUNG GALAXY TAB S10 FE v2.0

Bu Android sürümü iOS v1.6'nın özelliklerini Samsung Galaxy Tab S10 FE'ye port eder.

ÖZELLİKLER
• iOS ile aynı sade 5 ana menü:
  Ana / Testler / Favoriler / Yanlışlar / Kayıtlı
• Genel Kültür: 409 soru.
• TÜM testlerde her başlangıçta:
  - soru havuzu yeniden seçilir,
  - soru sırası yeniden karışır,
  - her sorunun A/B/C/D şıkları yeniden karışır.
• Doğru cevap hiçbir şıkta sabit değildir.
• Şık eleme / geri alma.
• Test kaydetme:
  - örneğin 6. soruda kaydedersen 6. sorudan devam eder,
  - soru sırası korunur,
  - o sorudaki şık sırası korunur,
  - elenen şıklar korunur,
  - cevaplanmış/cevaplanmamış durum korunur.
• Favoriler:
  - her kaynak/bölüm ayrı klasör,
  - 10 / 20 / tüm favorilerden sınav,
  - favoriler sınav çözülünce silinmez,
  - sadece kullanıcı silerse kaldırılır.
• Yanlışlar:
  - her kaynak/bölüm ayrı kutu,
  - yanlışlardan sınav,
  - bölümün yanlış sınavı tamamlanınca o bölümün yanlış kaydı temizlenir.
• Ana sayfa kalıcı istatistikleri:
  çözülen / doğru / yanlış / kayıtlı yanlış.
• Her test kartında son sonuç:
  doğru/toplam + yüzde.
• Anayasa 108 kısa geri dönütleri korunur.
• Tablet için geniş kartlar ve adaptif çok sütunlu düzen.
• Tamamen çevrimdışı.

GITHUB'DAN APK
1. ZIP'i çıkar.
2. Bu klasörün İÇİNDEKİ tüm dosya/klasörleri GitHub repo köküne yükle.
   Repo ana diziminde şunlar görünmeli:
   - .github
   - app
   - build.gradle
   - settings.gradle
   - gradle.properties
3. Commit changes.
4. GitHub > Actions > Build Samsung Tab S10 FE APK.
5. Run workflow.
6. Yeşil tamamlanınca sayfanın altındaki Artifacts:
   Sivil-Savunma-Samsung-Tab-S10FE-v2.0-APK
7. ZIP'i indir; içindeki app-debug.apk tabletine kurulacak dosyadır.

NOT
Eski Android v4/v5 kaynaklarıyla karıştırma. Bu proje ayrı ve sıfırdan Jetpack Compose portudur.
